# 建置與環境

從零把文字轉漫畫跑起來。指令都在 Windows PowerShell 執行。

## 1. 需要的東西

| 項目 | 版本／說明 | 用在 |
|---|---|---|
| Python | 3.10 以上 | 本工具 |
| git | 任何近期版本 | 版本控制 |
| ComfyUI | **0.42.0 以上**（MOSS-Image 需要） | 出圖 |
| MOSS-Image 模型 | 見第 4 節 | 出圖 |
| DeepSeek API 金鑰 或 llama.cpp | 二擇一，S4 起需要 | 改編、劇本、分鏡 |
| 中文字型 | 嵌字用，S3 起需要，見第 7 節 | 嵌字 |

不需要 Node、npm 或任何建置工具。

## 2. 這個專案是怎麼產生的

骨架用 fekit 的 `new_project.py` 產生（模組：`i18n`、`md`、`filepicker`、`table`），再加上漫畫專用的 `t2c/`（格子模板與 MOSS workflow 在 `t2c/data/`，M1 修正從 `layouts/`、`workflows/` 搬進來）、`tools/`、`examples/`、`docs/`。等同於：

```powershell
python <fekit 專案根>\tools\new_project.py <專案根目錄> --name text2comics --title "文字轉漫畫" --modules i18n,md,filepicker,table
```

所以 fekit 的 `docs/04_新專案建置步驟.md` 寫的寫法（頁面、任務面板、多語系）在這裡都適用。

## 3. 安裝

```powershell
cd <專案根目錄>
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.json config.json
python -m pytest tests
```

應該看到全部通過（S3 時是 120 項；嵌字的測試需要一套中文字型，找不到會跳過）。PowerShell 擋下 `activate` 的話，改用 `.venv\Scripts\python.exe -m pytest tests`。

### 啟動介面

```powershell
python run.py          # 或雙擊 start.bat；--port 9000 換埠、--no-open 不開瀏覽器
```

左側「任務」→「編譯範例分鏡」：右邊面板列出 5 格的尺寸與 seed，結果寫到 `examples\sample_comic\build\ch001\`。

## 4. ComfyUI 與 MOSS-Image

### 4.1 更新 ComfyUI

MOSS-Image 需要 ComfyUI 0.42.0 以上。更新後在 ComfyUI 的 Template 搜尋「MOSS-Image」，找得到就表示版本夠。（S1 實測：ComfyUI 0.41.0 也能用本工具的 workflow 正常出圖，含 4-step LoRA；官方需求以 0.42.0 為準，舊版出問題先更新。）

### 4.2 模型

從 Hugging Face `Comfy-Org/MOSS-Image` 下載，放到 ComfyUI 的 models 底下：

```
ComfyUI\models\
  diffusion_models\moss_image_sft_int8_convrot.safetensors     約 5.4 GB
  text_encoders\qwen3.5_9b_w4a8_gptq.safetensors               約 7.3 GB
  vae\flux2-vae_small.safetensors                               約 0.25 GB
```

Novel Studio 已經在用同一組檔案，不用重複下載。檔名不同的話，改 `config.json` 的 `comfy.models`。

### 4.3 設定

`config.json`：

```json
"comfy": {
  "url": "http://127.0.0.1:8188",
  "workflow": "",
  "models": { "unet": "...", "clip": "...", "vae": "..." },
  "default_preset": "final",
  "presets": {
    "final": { "steps": 25, "cfg": 2.5, "sampler": "er_sde", "scheduler": "simple" },
    "draft": { "steps": 4, "cfg": 1.0, "sampler": "euler", "scheduler": "simple",
               "lora": "ANIMA\\moss_image_sft_4step_v2.0.safetensors", "lora_strength": 1.0 }
  }
}
```

內建的 workflow 是 `t2c/data/moss_layout.api.json`（API 格式，25 步、CFG 2.5、`er_sde`）；`workflow` 留空（或舊寫法 `workflows/moss_layout.api.json`）就用它。要換參數，在 ComfyUI 裡調好後用選單 **Export (API)** 存成新檔，`workflow` 填它的路徑（相對路徑以 `config.json` 所在資料夾為準）；不要直接改內建檔，整合進別的專案時它會被覆蓋。規則：只能有一個 KSampler，正向／負向接 `CLIPTextEncode`（負向也可以接 `ConditioningZeroOut`）。

**出圖預設（`presets`）**：每組可以覆蓋 `steps`、`cfg`、`sampler`、`scheduler`，以及接一個 LoRA（`lora` 用 ComfyUI 列出的名稱，含子資料夾，如 `ANIMA\moss_image_sft_4step_v2.0.safetensors`；`lora_strength` 預設 1.0）。LoRA 會在 `KSampler` 的 model 前面自動接一個 `LoraLoaderModelOnly`。沒寫的欄位照 workflow。`default_preset` 是沒指定 `--preset` 時用的；沒有 `presets` 就完全照 workflow（與 0.1.0 相同）。

- `final`：照 workflow 的原設定，網點與墨線比較有漫畫感。
- `draft`：4 步＋LoRA（`akhaliq/MOSS-Image-SFT-4-steps`，Apache-2.0，`moss_image_sft_4step_v2.0.safetensors` 約 1.19 GB）。S1 實測約快 3.3 倍，線條較乾淨、漫畫網點較少。**LoRA 要放在 ComfyUI 看得到的 loras 路徑**（`extra_model_paths.yaml` 也可以），名稱要和 ComfyUI 列出的一致。
- 預設名稱只能由 `[a-z0-9_-]` 組成；`_` 開頭的鍵（例如 `_說明`）會被忽略。

### 4.4 試出圖

先開 ComfyUI，再：

```powershell
python tools\panels.py examples\sample_comic 1 --page 1 --render
python tools\panels.py examples\sample_comic 1 --page 1 --render --preset draft
python tools\panels.py examples\sample_comic 1 --page 1 --render --seed 1390808158
```

結果在 `examples\sample_comic\renders\ch001\`，檔名 `p001_k1_s<seed>.png`。已經存在的檔案會跳過，加 `--force` 重畫；`--candidates 4` 每格跑 4 個 seed。

- `--preset 名稱`：選出圖預設。不是 `default_preset` 的，檔名會加後綴，例如 `p001_k1_s1390808158_draft.png`，所以草稿不會蓋掉定稿。
- `--seed N`（可重複）：只畫指定的 seed，必須在該格的 `seeds` 裡。
- 建議流程：先 `--preset draft` 產每格 3 個候選、挑好，再用 `--preset final --seed <選定的 seed>` 重畫定稿。注意：同一個 seed 在草稿與定稿是**不同的圖**（步數、取樣器不同），定稿要重新確認。

### 4.5 顯示卡記憶體

- 主模型＋W4A8 文字編碼器約 13 GB，RTX 5070 Ti 16 GB 可以全放 GPU。
- 用 llama.cpp 做文字端時，**不要和 ComfyUI 同時載入模型**：文字端跑完、關掉或卸載 llama.cpp，再出圖。
- 想把文字編碼器移到 CPU，要換成 int8 版（`qwen3.5_9b_int8_convrot.safetensors`），並把 workflow 裡 `CLIPLoader` 的 `device` 改成 `cpu`；W4A8 在 CPU 上反而更慢。

### 4.6 選圖與組版（S2）

不需要 ComfyUI，只要 `renders\ch001\` 裡已有候選圖：

```powershell
python tools\pages.py examples\sample_comic 1 --list                          # 每格的候選與目前選的
python tools\pages.py examples\sample_comic 1 --pick p001_k1=1390808158      # 選圖，寫進 picks\ch001.json
python tools\pages.py examples\sample_comic 1 --focus p001_k1=0.3,0.6 --zoom p001_k1=1.5
python tools\pages.py examples\sample_comic 1                                 # 組版 → pages\ch001\p001.png
python tools\pages.py examples\sample_comic 1 --numbers                       # 每格標 slot 編號，檢查閱讀順序
```

- `--pick` 給 seed 時，檔名是 `<格 id>_s<seed>.png`；選草稿圖要給完整檔名（例如 `--pick p001_k1=p001_k1_s1390808158_draft.png`）。
- `--focus x,y` 是原圖上要留在格子中央的點（比例，左上 0,0）；`--zoom` 1–4。
- 預設轉灰階，`--color` 保留原色；`--out` 改輸出資料夾。
- 沒選圖的格會暫用第一個候選並列警告；沒有任何候選就放灰底。

## 5. 文字端 LLM（S4 起）

`config.json` 的 `providers` 與 Novel Studio 同格式。

- **DeepSeek**：金鑰先讀環境變數 `DEEPSEEK_API_KEY`；沒有就讀系統金鑰庫（Windows 認證管理員，服務 `novel-studio`、帳號 `deepseek`，和 Novel Studio、t2vn 同一筆，只讀不寫；要先在 `.venv` 裝 `pip install keyring`）。用環境變數的話，不要寫進檔案：

  ```powershell
  setx DEEPSEEK_API_KEY "你的金鑰"      # 設完要重開終端機
  ```

- **llama.cpp**：啟動 `llama-server`（OpenAI 相容端點 `http://127.0.0.1:8080/v1`），把 `model` 填成實際載入的模型名稱。分鏡 JSON 需要模型能穩定輸出 JSON，建議開 `json_mode`。

- **檢查連線**（S4）：

  ```powershell
  python tools\llm_check.py                    # 每個 provider 要一份 JSON，顯示用時與 usage
  python tools\llm_check.py --provider llamacpp --models   # 列出 llama-server 載入的模型名稱
  python tools\llm_check.py --stop-after 5     # 收到 5 個字就按停止，確認會中斷
  ```

  DeepSeek 的 `model` 要填帳號可用的模型名稱（`config.example.json` 的 `deepseek-flash` 是預設值，沒有實測過，連不上或 404 時先用 `--models` 查）。
- **重試與停止**：429、5xx、連線失敗會自動重試 3 次；金鑰錯誤（401）、餘額不足（402）、模型名稱錯（404）不重試，訊息會直接說原因。介面按停止後約 0.2 秒內中斷，連線一併切斷，llama.cpp 也會停止生成。
- **改編（S5）**：原著放 `<專案>\source\ch001.txt`，再執行：

  ```powershell
  python tools\adapt.py examples\sample_comic 1 --stage plan --show-prompt   # 只看提示詞，不需要金鑰
  python tools\adapt.py E:\comics\作品 1                     # 規劃 → 劇本 → 分鏡，全跑
  python tools\adapt.py E:\comics\作品 1 --stage storyboard  # 改過劇本後，只重做分鏡
  python tools\adapt.py E:\comics\作品 1 --stage script --page 3   # 只重寫第 3 頁劇本
  ```

  已存在的輸出不會被覆蓋（要重做加 `--force`）；驗證沒過會自動回修，最多 3 次（`--max-fix`）。模型原始輸出在 `build\adapt\ch001\`，忠實度報告在 `build\adapt\ch001_fidelity.md`。各階段的模型由 `stage_providers` 的 `adapt`／`script`／`storyboard` 決定。範例專案已經有 `script`、`storyboard`，要試跑請先複製一份到別的資料夾（或加 `--force`，之後用 `git checkout` 還原）。設計說明見 `docs/04_提示詞設計.md`。
- **token 估算**只是粗估（中文字乘 `cjk_token_ratio`），用來擋明顯放不下的提示詞；llama.cpp 要準的話之後可以用 `/tokenize` 校準。

## 7. 嵌字字型與設定（S3 起）

字型不隨專案發佈。挑可以商用、可以嵌入的開源字型，例如 Noto Sans CJK TC／Noto Serif CJK TC（SIL OFL）或 jf open 粉圓（SIL OFL）；把完整路徑填進 `config.json` 的 `lettering`。

```json
"lettering": {
  "dialogue_font": "C:\\Fonts\\NotoSansCJK-Medium.ttc",
  "shout_font": "C:\\Fonts\\NotoSansCJK-Black.ttc",
  "narration_font": "C:\\Fonts\\NotoSerifCJK-Medium.ttc",
  "sfx_font": "C:\\Fonts\\NotoSansCJK-Black.ttc",
  "vertical": true,
  "dialogue_pt": 9,
  "narration_pt": 8.5
}
```

| 欄位 | 預設 | 說明 |
|---|---|---|
| `dialogue_font` | 自動找 | 對話（`speech`、`thought`、`whisper`）的字型 |
| `shout_font` | 同 `dialogue_font` 加粗 | 喊叫（`shout`） |
| `narration_font` | 同 `dialogue_font` | 旁白方框（習慣用明體） |
| `sfx_font` | 同 `shout_font` | 狀聲詞（習慣用最粗的黑體） |
| `vertical` | `true` | 直排；`false` 橫排 |
| `dialogue_pt`、`narration_pt` | `9`、`8.5` | 字級（點）。依頁面 dpi（B5 1820 px 寬時是 254 dpi）換成像素，9 pt 約 32 px |

- 字型路徑可以是 `.ttf`、`.otf`、`.ttc`。`.ttc` 裡有多套字（例如 Noto CJK 的 JP／KR／SC／TC），沒指定時自動選名稱含 `TC` 或「正黑」「明」的那一套；要指定就在路徑後面加 `#索引`，例如 `NotoSansCJK-Medium.ttc#3`。
- 沒有設定時會依序找：Noto Sans／Serif CJK TC、思源黑體、微軟正黑體（`C:\Windows\Fonts\msjh.ttc`）、細明體。找到系統字型時組版會警告「暫用」：微軟正黑體可以自己看，**要發佈請換成開源字型**。
- 一個都找不到就停下來並告訴你要設定哪一欄，不會用沒有中文字的字型硬畫。

## 9. 常見問題

| 症狀 | 原因 | 解法 |
|---|---|---|
| `連不到 ComfyUI` | ComfyUI 沒開或埠不對 | 開 ComfyUI；改 `config.json` 的 `comfy.url` |
| `workflow 有錯：...` 提到 `EmptyFlux2LatentImage` 或 `moss_image` | ComfyUI 太舊 | 更新到 0.42.0 以上 |
| `UNETLoader 沒有設定模型檔名` | `config.json` 的 `comfy.models` 空白 | 填檔名（不含資料夾） |
| 出圖裡出現亂碼文字 | 模型自己加字 | 先換 seed；S1 會調整 caption 寫法 |
| 角色跑到不該出現的格子 | 分鏡的 `characters` 寫錯，或 `scene` 描述了不在場的人 | `scene` 只描述在場的人 |
| `ModuleNotFoundError: yaml` | 沒裝相依套件 | `pip install -r requirements.txt` |
| `找不到中文字型` | `config.json` 的 `lettering` 沒有設定，系統也沒有常見中文字型 | 安裝 Noto Sans CJK TC，把路徑填進 `lettering.dialogue_font` |
| 其他 fekit 相關錯誤（403、權杖） | — | 見 fekit 本體的 `docs/04_新專案建置步驟.md` 第 15 節 |
