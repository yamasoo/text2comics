## 1. 漫畫專案資料夾

一部漫畫一個資料夾，建議放在本工具外面（例如 `E:\comics\作品名`）；範例放在 `examples/` 只是為了測試。

```

  project.yaml
  bible\
    characters\<id>.md
    locations\<id>.md
    drafts\characters\<id>.md   卡片草稿（S6；人確認前，正文與編譯不讀）
    drafts\locations\<id>.md
    picks.json               定裝圖挑選紀錄（S6；人的決定，進版控）
  source\ch001.txt         原著章節（S5；.txt 或 .md，開頭可以有 frontmatter，會略過）
  plan\ch001.json          改編規劃（S5；LLM 產生、人可以改，進版控）
  script\ch001.md          漫畫劇本（人看、人改）
  storyboard\ch001.json    分鏡（機器讀）
  picks\ch001.json         選圖紀錄：每格選哪張候選、裁切焦點（S2；人的決定，進版控）

  renders\ch001\           出圖：<格 id>_s<seed>.png              ← 不進版控
  renders\bible\           S6 定裝圖候選：<工作 id>_s<seed>.png    ← 不進版控
  pages\ch001\             組版結果（S2 起）                      ← 不進版控
```

## 3. 視覺聖經

Markdown＋YAML frontmatter（與 Novel Studio 的設定集同一種寫法）。frontmatter 給程式，本文給人看。

### 角色 `bible/characters/<id>.md`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | `[a-z0-9_-]`，分鏡用這個指角色；檔名建議同 id |
| `name` | 是 | 顯示名稱 |
| `aliases` | 否 | 其他稱呼（S5 給 LLM 對應原著用） |
| `look_en` | 是 | **固定的英文外觀**：年齡、性別、髮型、臉部特徵、體型。不寫表情、動作、服裝。生圖時逐字使用，定案後不要改 |
| `outfits` | 否 | `{服裝 id: 英文完整句}`；`default` 是預設服裝。每句以 `He/She/They wears` 開頭，人稱要和 `look_en` 一致；不寫表情、動作；id 用 `[a-z0-9_-]` |
| `outfit_notes` | 否 | `{服裝 id: 中文說明}`，給人看（S6；程式不用，服裝矩陣會列出） |
| `status` | 否 | `draft`／`confirmed`（S6）。只在 `bible/drafts/` 用 `draft`；`accept` 搬進正式資料夾時改成 `confirmed`。舊卡片沒有這欄＝已確認 |

`look_en` 的檢查規則（`tools/bible.py check`，S6）：必須是英文、至少 6 個字、有性別字（man／woman／boy／girl…）與年齡字（young／middle-aged／mid-twenties…）；不得含服裝、表情、動作的字（清單在 `t2c/bible_check.py`）；沒提到頭髮只警告；超過 60 字警告。服裝缺 `default` 是錯誤。
### 地點 `bible/locations/<id>.md`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id`、`name` | 是 | 同上 |
| `look_en` | 是 | 固定的英文場景描述；不得出現人物字（person、man、crowd…，S6 檢查） |
| `outfit_notes`、`status` | 否 | 地點沒有服裝；`status` 同角色 |

卡片本文（frontmatter 之後）給人看，程式不讀。S6 產生的草稿本文固定有：摘要、`## 待確認`（補上的、與設定衝突的）、`## 登場章節`、`## 原文依據`（每條外觀都附原文逐字引文）。
## 4. 漫畫劇本 `script/chNNN.md`

給人讀、給人改的版本，也是**分鏡階段的唯一依據**：分鏡的台詞、旁白、狀聲詞必須和劇本逐字相同（S5 會檢查），所以要改台詞就改劇本，再重跑分鏡。S5 由 LLM 依改編規劃逐頁產生（`t2c/script.py` 解析）。

```markdown
---
chapter: 1
title: 章名
source: source/ch001.txt
pages: 頁數
---

# 第 1 話　章名

## 第 1 頁（模板 5a：上二中一下二）

**1 格**｜遠景、俯視｜畫面描述。
- 旁白：……
- 角色名：台詞
- 角色名（心聲）：……
- 角色名（喊）：……
- 角色名（通訊）：透過通訊器、電話傳來的聲音
- 角色名（畫面外）：人在附近、但這一格沒畫到他
- 狀聲詞：碰！

**2 格**｜特寫｜畫面描述。
- （無台詞）
```

| 項目 | 寫法 |
|---|---|
| 頁標題 | `## 第 N 頁（模板 K：名稱）`；模板 key 必填（名稱可省略），S5 產生時由程式統一寫法 |
| 格標題 | `**N 格**｜鏡頭詞、角度詞｜畫面描述`；N 依序是 1–模板格數 |
| 鏡頭詞（選一個） | 大遠景＝`extreme_wide`、遠景＝`wide`、全身＝`full`、中景＝`medium`、近景＝`close`、特寫＝`extreme_close` |
| 角度詞（可省略） | 平視＝`eye`、俯視＝`high`、仰視＝`low`、鳥瞰＝`bird`、斜角＝`dutch`、過肩＝`over_shoulder` |
| 台詞 | `- 角色名：台詞`，角色名是聖經的 `name`、`aliases` 或 id |
| 語氣標記 | `（心聲）`→ thought、`（喊）`／`（喊叫）`→ shout、`（小聲）`／`（悄聲）`→ whisper；沒標記是一般台詞（分鏡可依內容判斷成 speech、shout 或 whisper） |
| 聲音來源標記（M1 修正） | `（通訊）`／`（電話）`／`（廣播）`／`（無線電）`→ radio：透過機器傳來的聲音，說話的人通常不在這一格（分鏡用 `offscreen: true`）；不能再加語氣。`（畫面外）`→ 說話的人不在這一格的畫面裡（分鏡用 `offscreen: true`），可以和喊、小聲併用，寫成 `（畫面外、喊）`；不能和心聲併用 |
| 旁白、狀聲詞 | `- 旁白：…`（narration）、`- 狀聲詞：…`（或 `音效`） |
| 沒有台詞 | `- （無台詞）` |
| 限制 | 每格最多 3 個對話框（旁白算、狀聲詞不算）；一個對話框 45 字內；說話者要有角色卡（畫面外、通訊的也要） |

描述換行會併進同一格的描述。分鏡的鏡頭與劇本不一致只會提醒，不擋。

## 5. 分鏡 `storyboard/chNNN.json`

```json
{
  "version": 1,
  "chapter": 1,
  "title": "章名",
  "pages": [
    {
      "page": 1,
      "template": "5a",
      "panels": [
        {
          "slot": 1,
          "id": "p001_k1",
          "shot": "wide",
          "angle": "high",
          "location": "rooftop",
          "scene": "英文：這一格發生什麼事（不寫角色外觀）",
          "characters": [
            {"id": "lin", "outfit": "default", "pose": "英文姿勢", "expression": "英文表情", "box": [0.55, 0.45, 0.8, 0.9]}
          ],
          "objects": [{"caption": "英文物件描述", "box": [0.1, 0.1, 0.3, 0.3]}],
          "sfx": [{"text": "碰！", "box": [0.75, 0.05, 0.98, 0.4]}],
          "bubbles": [{"kind": "speech", "speaker": "lin", "text": "台詞", "anchor": [0.5, 0.2]}],
          "seeds": []
        }
      ]
    }
  ]
}
```

### 格（panel）欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| `slot` | 是 | 模板裡的格子編號（1 開始）；一頁的 slot 必須剛好是 1…模板格數 |
| `id` | 否 | 預設 `p<頁3位>_k<slot>`；檔名都用它。整章不能重複（頁碼也不能重複），存檔時擋 |
| `shot` | 否 | `extreme_wide`、`wide`、`full`、`medium`（預設）、`close`、`extreme_close` |
| `angle` | 否 | `eye`（預設）、`high`、`low`、`bird`、`dutch`、`over_shoulder` |
| `location` | 否 | 地點 id；有寫就把地點的 `look_en` 放進 caption，並加一個全畫面的背景 item |
| `scene` | 是 | 英文，這一格的畫面內容。**不寫角色外觀**，用 the young woman 之類的代稱 |
| `characters` | 否 | 在場角色。同一格同一角色只能一次。沒有人就給 `[]` |
| `characters[].box` | 否 | 比例框；省略時是畫面中間。**一格有 2 個以上角色時**，編譯會依框的中心點在該角色 caption 最前面加 `He/She is on the left/right side of the frame.`（中心 <0.4 為左、>0.6 為右，其餘為中間）。`over_shoulder` 會把背對鏡頭的角色放到前景左側而壓過 box（S1 實測），要用的話把背對鏡頭的角色 box 放左邊 |
| `objects` | 否 | 重要物件 |
| `sfx` | 否 | 狀聲詞；`sfx_mode = moss` 時才送進生圖 |
| `bubbles` | 否 | 對話框（**永遠不送進生圖**，給嵌字用），依閱讀順序排列，一格最多 3 個（S5 檢查）。`kind`：`speech`（橢圓）、`thought`（雲狀，尾巴是小圓點）、`shout`（爆炸形）、`whisper`（虛線橢圓）、`radio`（細密鋸齒外框的電子音框：通訊、電話、廣播）、`narration`（旁白方框，沒有尾巴）；`speaker` 必須是這一格在場的角色（旁白免填；畫面外的見下面「畫面外的說話者」），尾巴指向他的臉；`offscreen`（選填，預設 `false`）也見該小節；`anchor` 是對話框中心的**希望位置**，嵌字會從這裡出發，避開臉、其他對話框，找最近的空位。台詞裡的換行 `\n` 會強制換到下一行（直排時是下一欄）。嵌字沒有中文斷詞，S5 要求每行 ≤ 12 字（旁白 ≤ 16），超過要在詞與詞之間加 `\n` |
| `seeds` | 否 | 手動指定 seed；不夠的由格子 id 自動補 |

### 畫面外的說話者（M1 修正）

說話的人不在這一格的畫面裡——人在畫面外，或是透過通訊、電話從別處傳來——時，對話框加 `"offscreen": true`：

```json
{"kind": "radio", "speaker": "zhou_yuan", "offscreen": true, "text": "在。", "anchor": [0.6, 0.1]}
```

| 規則 | 說明 |
|---|---|
| `speaker` | 仍然必填，必須是聖經裡的角色，但**不可以**列在這一格的 `characters`（列了就是畫出來了，兩者矛盾） |
| 生圖 | 畫面外的說話者不送進生圖：不加 character item、不算進「exactly N people」 |
| 種類 | `speech`、`shout`、`whisper`、`radio` 可以；`thought`（心聲要看得到人）、`narration`（本來就沒有說話者）不行 |
| 尾巴 | `speech`、`shout`、`whisper`：指向離對話框最近的格框邊（左右兩邊優先），表示聲音從畫面外來；`radio`：沒有尾巴（鋸齒框本身表示電子音）。都可以在嵌字微調裡改 |
| `radio` 但說話者在畫面上 | 例如臉出現在螢幕上：不寫 `offscreen`，把他列進 `characters`，尾巴照常指向他 |
| 和劇本的對應 | 劇本 `（通訊）` → `kind` 必須是 `radio`；劇本 `（畫面外）` → 必須 `offscreen: true`。劇本沒標、分鏡自己決定不畫出說話者（例如只拍聽的人）也可以，加 `offscreen: true` 即可 |

### 座標

一律是比例 `[x0, y0, x1, y1]`：左上角 (0,0)、右下角 (1,1)，相對於**這一格**（不是整頁）。`anchor` 是 `[x, y]`。

精確地說，分鏡裡的座標（`characters[].box`、`objects[].box`、`sfx[].box`、`bubbles[].anchor`）都是相對於**這一格生成的圖**。組版時圖會依 `picks` 的 `focus`、`zoom` 裁切成格子的形狀（第 8 節），嵌字會把這些座標換算到裁切後的格子上，所以改了裁切，對話框與臉框會跟著圖走。沒有放大、焦點置中時，兩者幾乎相同。

## 6. 格子模板 `t2c/data/pages.json`

- `page`：頁面比例（B5，182×257 mm）、輸出寬度、頁邊（比例，[左, 上, 右, 下]）、格間白邊與框線粗細（像素）。
- `templates.<key>.panels`：格子框，比例座標、相對於頁面內框，**依右翻閱讀順序排列**（右上開始、同排由右到左、再下一排）。格子彼此相接，白邊在組版時才扣。

目前模板：`1`（全頁）、`2h`、`3a`、`4a`、`5a`、`6a`。新增模板要讓格子剛好鋪滿（測試會檢查）。

## 7. 編譯結果 `build/chNNN/<格 id>.prompt.json`

| 欄位 | 說明 |
|---|---|
| `id`、`page`、`slot` | 對應分鏡 |
| `rect_px` | 這一格在整頁上的像素框（組版用） |
| `width`、`height` | 生圖尺寸 |
| `layout` | 送給 MOSS 的 layout JSON（展開，方便人看） |
| `negative` | 負向提示詞 |
| `seeds` | 這一格要跑的 seed |

送給 ComfyUI 的正向提示詞就是 `json.dumps(layout, ensure_ascii=False)`。

## 8. 選圖紀錄 `picks/chNNN.json`（S2）

人的決定（選哪張、構圖怎麼裁），所以放在專案根目錄的 `picks/`、進版控；不要放進 `pages/`（那是產出，不進版控）。

```json
{
  "version": 1,
  "chapter": 1,
  "picks": {
    "p001_k1": {"image": "p001_k1_s1390808158.png", "focus": [0.5, 0.5], "zoom": 1.0}
  }
}
```

| 欄位 | 必填 | 預設 | 說明 |
|---|---|---|---|
| key（格 id） | — | — | 分鏡裡的格 id（`p001_k1`） |
| `image` | 是 | — | `renders/chNNN/` 底下的檔名（純檔名，不含路徑）。草稿與定稿是不同的檔，所以記檔名而不是 seed |
| `focus` | 否 | `[0.5, 0.5]` | `[x, y]` 比例，原圖上要盡量留在裁切框中央的點（0,0 是左上） |
| `zoom` | 否 | `1.0` | 1–4。1 是剛好蓋滿格子（cover）；大於 1 再放大，只留焦點附近 |

### 裁切規則（cover）

1. 縮放到剛好蓋滿格子（取寬、高兩個縮放比的較大者），再乘上 `zoom`。
2. 裁切框中心盡量對準 `focus`；框不會超出原圖，所以焦點靠近邊緣時，框會被推回圖內。
3. 沒有在 picks 裡的格：暫用 `renders/chNNN/` 裡該格第一個候選（`<格 id>_s<數字>.png`，依檔名排序），並在結果裡列警告；一張都沒有就畫灰底佔位格。

### 組版規則

- 頁面用 `t2c/data/pages.json` 的 `page`：寬 `width_px`、高依 B5 比例；內框 = 扣掉 `margin`。
- 每格框 = 模板格子（比例）換算成像素，相鄰兩格之間留 `gutter_px`（一格各扣一半）；貼圖後在格子邊緣畫 `frame_px` 的黑框（畫在格子內側，不會吃掉白邊）。
- 預設輸出灰階（模式 `L`）：消除 S1 看到的輕微偏色。`--color` 保留原色。
- PNG 內附 dpi（由頁寬 mm 與像素換算）。

## 9. 組版結果 `pages/chNNN/pNNN.png`（S2）

每頁一張 PNG，不進版控。`tools/pages.py --numbers` 會在每格角落標上 slot 編號，只用來檢查閱讀順序，不是正式輸出。

## 10. 嵌字微調 `letters/chNNN.json`（S3）

嵌字預設全自動：依分鏡的 `anchor` 找位置、從 `characters[].box` 推估臉的位置來避開、尾巴指向說話者的臉。自動結果不滿意時，在介面拖曳（或手改這個檔），覆寫只記**和自動不同的部分**。跟 `picks` 一樣是人的決定，放在專案根目錄的 `letters/`、進版控。

```json
{
  "version": 1,
  "chapter": 1,
  "panels": {
    "p001_k5": {
      "faces": [[0.05, 0.08, 0.3, 0.36], [0.58, 0.02, 0.86, 0.34]],
      "bubbles": [
        {"text": "妳上次說的，不要香菜。", "center": [0.45, 0.13], "tail": [0.66, 0.3]},
        {"text": "……記得這種事幹嘛。", "scale": 0.9, "rows": 5}
      ],
      "sfx": []
    }
  }
}
```

**座標**：這個檔的座標是相對於**組版後看到的格子**（裁切之後），比例 `[x, y]`／`[x0, y0, x1, y1]`，左上 (0,0)。和分鏡不同，因為這是人在成品上拖出來的位置。

### 格（key 是分鏡的格 id）

| 欄位 | 必填 | 說明 |
|---|---|---|
| `faces` | 否 | 這一格**所有**要避開的臉框。有寫就取代自動推估（`[]` 表示不避開任何東西）；沒寫就自動推估 |
| `bubbles` | 否 | 依分鏡 `bubbles` 的順序一一對應；不需要改的那一個寫 `{}` 或 `null`。比分鏡多出來的會被忽略並警告 |
| `sfx` | 否 | 依分鏡 `sfx` 的順序一一對應，寫法同上 |

### 對話框覆寫（`bubbles[]`）

| 欄位 | 預設 | 說明 |
|---|---|---|
| `text` | — | 存檔時的台詞，用來比對。分鏡的台詞改過、和這裡不同時，會警告「微調可能不適用」，但照樣套用 |
| `center` | 自動 | 對話框中心 `[x, y]`。有寫就固定在這裡，不再自動找位置（仍會限制在格子內） |
| `tail` | 自動 | 尾巴尖端 `[x, y]`；`null` 表示不要尾巴。旁白永遠沒有尾巴 |
| `scale` | `1.0` | 字級倍率 0.5–2 |
| `rows` | 自動 | 直排時每欄最多幾個字（橫排時是每行），1–40；用來改對話框的形狀 |

### 狀聲詞覆寫（`sfx[]`）

| 欄位 | 預設 | 說明 |
|---|---|---|
| `box` | 分鏡的 `box`（換算到格子） | 狀聲詞要填滿的框 |
| `angle` | `-8` | 旋轉角度（度，-45–45；正數是逆時針） |
| `vertical` | 自動 | `true` 直排、`false` 橫排；自動時框高大於寬就直排 |

### 嵌字規則

- **對話框形狀**：`speech` 橢圓、`thought` 雲狀＋小圓點、`shout` 爆炸鋸齒、`whisper` 虛線橢圓、`radio` 細密鋸齒的橢圓（電子音）、`narration` 直角方框。
- **直排**（`config.json` 的 `lettering.vertical`，預設 `true`）：欄由右到左，每欄置中。標點依台灣直排習慣：`，。、！？` 放在字格正中；`「」『』（）《》〈〉【】…—～：；` 轉 90 度；`！？`、`!?`、兩位以內的半形數字併成一格橫排（縱中橫）。
- **斷行禁則**：`，。、！？」』）…` 等不放在欄首（必要時懸在欄尾，最多一格）；`「『（` 等不放在欄尾；`……`、`——` 不拆開。
- **自動位置**：從 `anchor` 附近找格子內的空位，成本依序是：壓到臉（極高）、壓到其他對話框（極高）、閱讀順序顛倒、離 `anchor` 的距離、壓到角色身體。避不開臉時照樣放，但會警告。
- **閱讀順序**（M1 修正）：右翻時後一個對話框會先被讀到——整個在前一個上面、跑到右上方、或差不多高（起頭差 8% 內）但整個在右邊——就算顛倒。擺完全部對話框再檢查一次，顛倒的列警告（嵌字頁畫成紅框），手動固定的位置也一樣。在右下方、起頭明顯比較低的不算（讀者多半先往左讀）。
- **尾巴**：指向說話者臉框的下緣中央，尖端停在臉外；說話者沒有臉框（例如 `faces: []`）時指向他的 `box` 上緣。`offscreen` 的對話框見第 5 節（指向格框邊，`radio` 沒有尾巴）。
- **狀聲詞**：`sfx_mode = overlay` 時由嵌字疊上：黑字白邊、填滿框、預設稍微傾斜。`moss` 時交給 MOSS 畫，嵌字不處理。
- 字放不下（對話框比格子大）時，字級自動縮小到 0.6 倍為止，仍放不下就警告。

## 11. 原著 `source/chNNN.txt`（S5）

純文字或 Markdown，UTF-8。開頭的 YAML frontmatter 會被略過（方便從 Novel Studio 匯出）。整章會放進提示詞，太長時 `check_context()` 會擋下。

## 12. 改編規劃 `plan/chNNN.json`（S5）

LLM 產生、人可以改（進版控）；劇本階段依它逐頁寫。

```json
{
  "version": 1,
  "chapter": 1,
  "title": "遲到的便當",
  "summary": "一句話：這一章發生什麼",
  "pages": [
    {
      "page": 1,
      "template": "5a",
      "purpose": "這一頁在章裡的作用",
      "hook": "頁末的翻頁點（可空）",
      "panels": [
        {"slot": 1, "beat": "這一格發生什麼（中文）", "source": "原著依據（短引文）", "characters": ["lin"], "location": "rooftop"}
      ]
    }
  ],
  "omitted": ["刪掉的原著內容與理由"],
  "unlisted_characters": ["原著有、聖經沒有角色卡的人物"]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `pages[].page` | 是 | 從 1 連號 |
| `pages[].template` | 是 | `t2c/data/pages.json` 的模板 key |
| `pages[].purpose` | 是 | 這一頁的作用 |
| `pages[].hook` | 否 | 頁末的翻頁點 |
| `pages[].panels[].slot` | 是 | 依序是 1–模板格數 |
| `pages[].panels[].beat` | 是 | 這一格演什麼 |
| `pages[].panels[].source` | 否 | 原著依據，給人對照；要引原文（可用「……」省略中間），找不到時提醒（M1 修正） |
| `pages[].panels[].characters` | 否 | 角色 id（必須在聖經） |
| `pages[].panels[].location` | 否 | 地點 id |
| `omitted` | 否 | 刪減清單，給人工審閱 |
| `unlisted_characters` | 否 | 聖經缺的角色；要讓他們入鏡，先補角色卡（S6 會自動化） |

## 13. 視覺聖經的工作檔（S6）

```
build\bible\scan\chNNN.json     每章掃描結果（原文雜湊相同就沿用；原文改了才重掃）
build\bible\entities.json       合併後的證據：每個角色／地點在哪些章出現、原文寫了什麼外觀與服裝（含引文）
build\bible\sheets.json         定裝圖工作清單：工作 id → {kind, id, outfit, view}
build\bible\contact_<類別>_<id>.jpg   候選比較表（人看）
build\bible\matrix.md           服裝矩陣（人看）
build\bible\raw\               模型原始輸出（回修失敗時看這裡）
renders\bible\                  定裝圖候選
bible\picks.json                挑選紀錄
```

- **掃描結果** `scan/chNNN.json`：`characters[]`、`locations[]`，每項有 `name`、`gender`（角色）、`looks[]`／`outfits[]`。每條外觀事實是 `{en, quote}`，`quote` 必須是該章原文的逐字片段（忽略空白）；對不上的整條丟掉，不補。
- **卡片草稿**：和正式卡片同一格式，另有 `status: draft` 與 `outfit_notes`。`invented`（補上的）與 `conflicts`（設定與原文不同）寫在本文的「待確認」。原文與作者設定衝突時以原文為準。
- **定裝圖工作 id**：角色 `ref_c_<角色id>_<服裝id>_<視角>`，視角 `full`（全身）、`bust`（胸像）；地點 `ref_l_<地點id>`。角色 3:4、地點 4:3。實際用單格合成模板走 `compile_chapter()`，所以角色外觀仍只來自 `look_en`／`outfits`；種子由工作 id 決定，同一張重跑結果一樣。
- **`bible/picks.json`**：

  ```json
  {"characters": {"su_yan": {"default": {"image": "ref_c_su_yan_default_full_s123.png", "signature": "ab12cd34ef", "picked": "2026-11-08"}}},
   "locations": {"old_conduit": {"image": "ref_l_old_conduit_s456.png", "signature": "…"}}}
  ```

  `signature` 是 `look_en`＋服裝句的雜湊；定案後又改了 `look_en` 或服裝，`status` 會標 ⚠ 過期，要重畫重挑。

## 15. 輸出 `out/chNNN.pdf`、`out/chNNN.cbz`（S8）

把已經輸出的 `pages/chNNN/pNNN.png` 打包；**不重新組版**，所以要先輸出頁面（缺任何一頁就報錯，一次列出缺的頁碼）。`out/` 不進版控。單頁輸出叫 `chNNN_pNNN.pdf`／`.cbz`。頁面 PNG 比分鏡、`picks/`、`letters/` 舊時列提醒（可能不是最新）。同樣的輸入產生同樣的位元組（不寫時間戳）。

**右翻**：本工具只做日式右翻（`project.yaml` 的 `reading: rtl`），頁序是第 1 頁在最前面，方向由檔案裡的旗標告訴閱讀器。

| 格式 | 內容 |
|---|---|
| PDF | 每頁一張影像（灰階 `DeviceGray`、彩色 `DeviceRGB`），頁面大小 = 像素 ÷ PNG 的 dpi × 72 pt（B5 是 515.9 × 728.5 pt）。`/ViewerPreferences << /Direction /R2L >>`；`/PageLayout /TwoPageRight`（雙頁檢視，第 1 頁單獨在右；只有一頁、或指定單頁檢視時用 `/SinglePage`）；`/Lang`（`project.yaml` 的 `language`）；`/Title`＝「作品名　第 N 章　章名」。內頁預設 JPEG 品質 90，可改品質或選無損（Flate）。 |
| CBZ | ZIP：`p001.png`…（PNG 原檔，不重新壓縮）＋ `ComicInfo.xml`：`Series`（作品名）、`Title`（章名）、`Number`（章號）、`PageCount`、`LanguageISO`、`BlackAndWhite`、`Manga` = `YesAndRightToLeft`、`Pages`（第 1 頁 `FrontCover`、每頁寬高）。 |
