# S3 嵌字驗收（2026-11-08）

環境：雲端 Linux、Python 3.13、Pillow 12.3、字型 Noto Sans／Serif CJK TC（自動找到）。圖是 S1 初選的 5 張（`examples/sample_comic/picks/ch001.json`）。
**還沒在你的 Windows 上跑過**：那邊沒有設定字型時，會自動用微軟正黑體（對話、喊叫、狀聲詞）與細明體（旁白），字形會和下面的圖不同。

## 1. 驗收項目

| 項目 | 結果 | 怎麼確認 |
|---|---|---|
| 範例頁所有台詞可讀 | ✅ | 目視 `S3_picks/p001_lettered.jpg`、`k1_detail.jpg`、`k5_detail.jpg`；7 句台詞＋1 個狀聲詞都在，沒有被裁切或縮小（沒有「字級自動縮成」的警告） |
| 不壓到角色臉 | ✅（自動推估的臉框） | `S3_picks/p001_guides.jpg` 的灰框是推估的臉；測試 `test_sample_plan_keeps_bubbles_inside_panels_and_off_faces` 確認每個對話框和臉框重疊面積為 0。目視：k5 兩句在兩人之間與左下，k4 在右上天空，k3 在左側天空，k1 在水塔前 |
| 標點直排正確 | ✅ | `，。` 在字格正中（測試量墨跡中心誤差 ≤ 3 px）；`……` 轉成直的、兩格不拆開；`！` 直立；欄首沒有標點、欄尾沒有開括號（禁則測試 25 組） |
| 可在介面拖曳微調 | ✅ | 用 Playwright 在「嵌字」頁拖對話框、拖尾巴、改每欄字數、拖臉框，按存檔；`letters/ch001.json` 寫入 3 格的覆寫，頁面 PNG 重新輸出（`S3_picks/editor.jpg`，在範例的複本上做，範例本身沒有 letters 檔） |

## 2. 看到的問題與處理

| 問題 | 處理 |
|---|---|
| 沒有中文斷詞，長句會在詞中間斷欄（「被教／授」「說／的」） | 在標點後優先換欄（往回最多 1/3 欄）；評分扣「斷在句中」。仍不夠時，分鏡台詞用 `\n` 手動分句（範例 k3、k5 已加）。S5 要讓 LLM 產生 `\n`（已記 backlog） |
| 短句被排成兩欄（「……／又不接。」） | 6 格以內的台詞優先一欄到底 |
| k5 的對話框蓋住便當（重要物件） | `objects` 的框也列入避開成本（權重低於臉） |
| 尾巴目標：分鏡的角色框不一定準（S1：角色常不照框畫） | 臉框可以在介面拖、縮放、新增、刪除；改了之後尾巴自動改指向新的臉框 |
| `getbbox()` 的水平範圍是字寬不是墨跡，句號置中會偏 7 px | 改成實際畫一次量墨跡（`_ink_offset`，有快取） |

## 3. 數字

- 一頁 5 格、7 個對話框＋1 個狀聲詞：命令列組版＋嵌字約 0.6 秒；介面拖曳預覽一次約 0.2 秒（沒有字的頁面有快取）。
- 字級：對話 9 pt、旁白 8.5 pt，在 254 dpi（B5 寬 1820 px）是 32 px／30 px。

## 4. 待你確認

1. 在 Windows 上 `python -m pytest tests`，以及 `python tools\pages.py examples\sample_comic 1` 的輸出（字型會是微軟正黑體／細明體，除非你在 `config.json` 的 `lettering` 填了開源字型）。
2. `python run.py` →「嵌字」頁：拖一下對話框和臉框，看預覽有沒有跟上、存檔後 `examples\sample_comic\letters\ch001.json` 的內容。範例不需要微調，試完可以刪掉這個檔。
3. 字級 9 pt 是否太大或太小（印成 B5 時）；要改就改 `lettering.dialogue_pt`。
