# S6 視覺聖經：在你的電腦上驗收

雲端沒有 ComfyUI 與 DeepSeek 金鑰，下面是需要你在 Windows 上做的項目。每項做完把結果寫在「記錄」欄。

## 0. 準備

```powershell
cd E:\dev\text2comics
python -m pytest tests
```

→ 全部通過（雲端 Linux 是 230 項）。

把草稿專案放到工作位置（`work\` 不進版控）：

```powershell
python tools\bible.py check work\mars_war
```

→ 應該顯示 17 份卡片、0 份有錯誤。

## 1. 先確認草稿卡（人工，最重要）

打開 `work\mars_war\bible\drafts\characters\*.md`，看每張卡的「待確認」與「原文依據」。至少決定：

- 蘇硯的髮型（紮起或不紮）
- 莫蘭、周遠、陶伯、阿海、兩個守門人要長什麼樣（原文沒寫的部分）
- 種族是不是都用東亞（可以改 `look_en` 裡的 `East Asian`）
- 工具間要不要畫成燒毀前

改完 `look_en` 後再：

```powershell
python tools\bible.py check work\mars_war
python tools\bible.py accept work\mars_war --all
```

## 2. 定裝圖（需要 ComfyUI）

先設 `config.json`（從 `config.example.json` 複製），啟動 ComfyUI，再：

```powershell
python tools\bible.py sheet work\mars_war --render --candidates 3
```

結果在 `work\mars_war\renders\bible\`，比較表在 `work\mars_war\build\bible\contact_*.jpg`。看：

| 檢查 | 記錄 |
|---|---|
| 性別、年齡對不對 | |
| 髮型髮色對不對 | |
| 是不是只有一個人（沒有多人） | |
| 黑白、網點乾不乾淨，有沒有多出的字 | |
| 全身像的臉會不會太小（太小就只出胸像：`--views bust`，或加大 `--megapixels`） | |
| 服裝有沒有照句子畫（蘇硯 `default` 與 `corridor_helmet` 看得出差別） | |
| 地點是不是畫成空景（沒有人） | |
| 每張約幾秒 | |

不滿意的角色：改卡片的 `look_en`（先 `check`），只重畫他：

```powershell
python tools\bible.py sheet work\mars_war --only su_yan --render --force
```

滿意的挑一張：

```powershell
python tools\bible.py pick work\mars_war ref_c_su_yan_default_full_s123.png
python tools\bible.py status work\mars_war
```

驗收標準：**主要角色（陳嘉禾、蘇硯、莫蘭、周遠）都有卡片與挑好的定裝圖**，`build\bible\matrix.md` 的「定裝圖」欄沒有「未挑」。

## 3. 真的 DeepSeek 抽取（選做，驗證流程）

```powershell
setx DEEPSEEK_API_KEY "你的金鑰"
python tools\bible.py extract E:\comics\mars_test --from "C:\Users\<你>\Documents\小說\第一次火星獨立戰爭\正文" --notes "C:\Users\<你>\Documents\小說\第一次火星獨立戰爭\設定"
```

（先 `xcopy` 一份空的專案，只要有 `project.yaml`。）記下：

- 掃描有沒有漏掉主要角色？
- 有多少條引文對不上而被丟掉（會列在輸出的提醒裡）？
- 每張卡回修幾次？`look_en` 常犯什麼錯？
- 和 `work\mars_war` 的手工草稿比，差在哪？

這些會用來調整 `t2c/bible_prompts.py`。
