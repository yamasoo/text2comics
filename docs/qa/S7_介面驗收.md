# S7 介面驗收（在你的 Windows 電腦上做）

雲端只用假的 ComfyUI 與假模型驗過。這份清單用真的服務走一次「不碰命令列完成範例一章」。

## 準備

1. ComfyUI 開著（`config.json` 的 `comfy.url`），MOSS-Image 的模型已放好。
2. 文字端：DeepSeek（環境變數 `DEEPSEEK_API_KEY` 或金鑰庫）或 llama-server。
3. 在專案資料夾執行一次測試：`.venv\Scripts\python -m pytest tests -q`（應全過；`test_smoke.py` 的出圖煙霧測試需要 ComfyUI）。
4. 雙擊 `start.bat`。

## 步驟與要看的地方

| # | 做什麼 | 要確認 |
|---|---|---|
| 1 | 專案頁「環境」 | ComfyUI 顯示已連線與 VRAM；DeepSeek 顯示「有金鑰」；llama.cpp 開著時顯示「執行中」 |
| 2 | 新建專案 → 選「複製範例」（不勾出圖）→ 建立 | 章節表出現第 1 章：原著、劇本、分鏡有，出圖 0／5 |
| 3 | 第 1 章 →「規劃」→ 產生改編規劃 | 右邊任務面板看到模型輸出；完成後頁面自動顯示規劃表 |
| 4 | 「劇本」→ 重新產生（只重寫第 1 頁）| 只第 1 頁被改；按「編輯」改一句台詞、存檔，檢查結果有顯示 |
| 5 | 「分鏡」→ 點第 5 格 | 右側（或下方）出現編輯區：拖角色框、對話框藍點；「送給 MOSS 的提示詞」跟著變 |
| 6 | 把第 5 格的 scene 加上 "wears a red coat" → 存檔 | 存得進去，但上方提醒「外觀」；改回來再存 |
| 7 | 「出圖」→ 整章出圖 | 用 llama.cpp 而且它還開著時，任務會停下來問；關掉 llama-server 按「已關閉，繼續」。每格 3 張依序出現；記下每張秒數 |
| 8 | 每格點一張縮圖 | 綠框標「已選」；重新整理頁面仍在 |
| 9 | 第 3 格「裁切」→ 點焦點、放大 1.5 → 存檔 | 右邊預覽跟著變；「頁面」分頁的預覽也變了 |
| 10 | 第 2 格「加畫 2 張」 | 多出 2 張新 seed，舊的沒被覆蓋 |
| 11 | 某一張「重畫」 | 只有那一張被覆蓋（同 seed 圖應幾乎相同） |
| 12 | 「頁面」→ 輸出整章頁面 →「嵌字微調」拖一個對話框 → 存檔 | `pages\ch001\p001.png` 更新 |
| 13 | 視覺聖經 → 新增一張卡片草稿 → 填 look_en → 確認入庫 → 出定裝圖 → 挑一張 | 狀態從「未挑」變「已挑」；再改 look_en 存檔，提醒「過期」 |
| 14 | 開 `work\mars_war`（把路徑貼到「開啟專案」）→ 視覺聖經 | 草稿看得到「待確認」與原文依據並排 |
| 15 | 任何任務執行中按「停止」 | 幾秒內停下；已出的圖保留 |
