# 介面設計（S7）

目標：**不碰命令列完成一章**——開專案 → 原著 → 改編規劃 → 劇本 → 分鏡 → 逐格出圖、挑圖 → 嵌字 → 頁面。命令列工具（`tools/*.py`）照舊可用，介面和它們呼叫同一批 `t2c` 函式。

## 1. 原則

1. **核心不知道介面**：介面需要、命令列也用得到的邏輯放 `t2c/`（`workspace.py`、`render.py`、`gpu.py`）；`server/` 只做參數檢查、錯誤轉成 `ApiError`、把核心包成背景任務。
2. **專案由瀏覽器記住**：目前開的漫畫專案資料夾存在瀏覽器（`FE.store` 的 `project`），每個 API 都帶 `project`（資料夾路徑）。後端不存「目前專案」，所以重新啟動、開兩個分頁都不會亂。最近開過的專案也記在瀏覽器。
3. **人的決定立刻存檔，產出另外產生**：挑圖、裁切焦點按了就寫 `picks/`；分鏡、劇本、原著、聖經卡片按「存檔」才寫；頁面 PNG 由「輸出頁面」任務產生。
4. **長工作一律是背景任務**（LLM、出圖、整章組版），進度顯示在右邊的任務面板，可以停止。任務**排隊執行、同時只跑一個**（`JobRunner(queue=True)`），所以 LLM 與 ComfyUI 不會被本工具同時叫起來。
5. **人改的檔案只擋「編譯不了」**：LLM 的輸出要過全部檢查（CLAUDE.md 規則 6）；人在介面改的分鏡只要能 `compile_chapter()` 就能存，其他檢查（外觀字、每行字數、和劇本不一致）列成提醒，人自己決定。劇本、原著、卡片也一樣：存檔後顯示檢查結果，不擋。
6. 介面文字繁體中文；檔案、欄位、CSS class 英文。

## 2. 頁面

| 網址 | 頁面 | 內容 |
|---|---|---|
| `#/` | 專案 | 開啟（路徑或瀏覽）、最近開過、新建、從範例複製；目前專案的章節表（每章各階段有沒有檔案、出圖與選圖進度）、視覺聖經摘要、環境檢查（ComfyUI、各 provider 金鑰／連線） |
| `#/chapter/:n` | 章節 | 分頁（`?tab=`）：原著、規劃、劇本、分鏡、出圖、頁面；頂端「整章批次」 |
| `#/bible` | 視覺聖經 | 草稿（本文＋原文引文並排、改卡片、確認入庫）、定案卡片（定裝圖候選、挑選、重畫）、抽取任務 |
| `#/letter` | 嵌字 | S3 的頁面；沒帶 `project` 時用目前專案。右翻順序顛倒的對話框畫成紅框（M1 修正） |

### 章節的分頁

- **原著**：貼上或從檔案匯入（`source/chNNN.txt`），顯示字數與 token 估計。
- **規劃**：表格看每頁每格的節拍與原著依據、刪減清單、聖經缺的人物；「產生規劃」任務（可指定頁數、章名）；進階：直接改 JSON（存檔前過 `check_plan`，有錯擋下）。
- **劇本**：Markdown 檢視／編輯；「產生劇本」任務（全部，或只重寫某一頁）；忠實度報告。
- **分鏡**：一頁一張表，一格一列（鏡頭、角度、地點、畫面、角色、台詞）。點一列打開這一格的編輯區（對話框可勾「畫面外」：說話的人不在這一格，或透過通訊說話，這時說話的人可以選不在場的角色；M1 修正）：欄位表單＋框編輯器（在這一格的比例畫布上拖角色框、物件框、狀聲詞框、對話框 anchor；有選圖就用它當底圖），以及編譯後送給 MOSS 的提示詞。「產生分鏡」任務（全部或某一頁）。
- **出圖**：一格一張卡片，列出候選縮圖；點縮圖＝選圖（立刻寫 `picks/`）；裁切編輯（拖焦點、調放大，即時看到格子裡的樣子）；「出圖」任務：整頁、只這一格、加畫 N 張（新 seed）、同 seed 重畫；出圖預設（`final`／`draft`）。
- **頁面**：每頁的嵌字預覽（即時組版＋嵌字，不寫檔）、到嵌字頁微調、「輸出頁面」任務（寫 `pages/chNNN/`）。**下載（S8）**：整章 PDF／CBZ 與每頁的「這頁 PDF」，用已輸出的頁面 PNG 打包（右翻，格式見 `docs/02_資料格式.md` 第 15 節），同時存在專案的 `out/`；頁面 PNG 沒輸出齊時按鈕停用並說明原因，PNG 比分鏡／選圖／嵌字舊時顯示提醒；可勾「PDF 用單頁檢視開啟」。打包很快（幾秒），所以是同步下載，不走背景任務。

## 3. 新 seed 怎麼來（「加畫」）

seed 仍由格子 id 決定（`compile._seed(格 id, 候選編號)`，CLAUDE.md 規則 7）。「加畫 N 張」從候選編號 0 往上找，跳過檔案已經存在的，取前 N 個——所以加畫的結果也可重現，且不會覆蓋任何舊圖。「同 seed 重畫」只在明確選了某一張時提供（會覆蓋該檔）。

## 4. VRAM 排程（`t2c/gpu.py`）

本機 llama.cpp 與 ComfyUI 不同時佔 GPU（16 GB 放不下兩邊）：

1. 任務排隊、一次一個（見原則 4）。
2. **呼叫本機 LLM 前**：對 ComfyUI 送 `POST /free`（`unload_models`、`free_memory`），把模型卸下。ComfyUI 沒開就略過。
3. **出圖前**：檢查設定裡的本機 provider（網址是 localhost）是否還在執行（`GET /health`）。還在的話，任務**暫停並詢問**：關掉 llama-server（或卸載模型）後按「繼續」；也可以選「照樣出圖」或「停止」。用 DeepSeek 時沒有這一步。
4. 整章批次依序：規劃 → 劇本 → 分鏡（LLM）→（第 2、3 點）→ 出圖 → 輸出頁面。每一步都會跳過已經有的檔案（除非勾「重做」），中途停止後再按一次會接著做。

llama-server 目前沒有通用的「卸載模型」API（只有 router 模式有），所以第 3 點用詢問而不是自動卸載（待後續處理）。

## 5. API（`server/`）

所有端點都帶 `project`（GET 用 query、POST 用 body）。錯誤用 `ApiError(400, 訊息, code)`。

| 方法 | 路徑 | 說明 |
|---|---|---|
| GET | `/api/project` | 專案總覽：設定、章節表、聖經摘要 |
| POST | `/api/project/create` | 新建專案（`path`、`title`、`style`；`from_sample: true` 複製範例） |
| GET | `/api/env` | 環境：ComfyUI 是否連得上、各 provider 有沒有金鑰、本機 LLM 是否在執行 |
| GET／POST | `/api/chapter/source` | 原著讀寫（POST `text` 或 `path` 匯入） |
| GET／POST | `/api/chapter/plan` | 規劃讀寫（POST 過 `check_plan`） |
| GET／POST | `/api/chapter/script` | 劇本讀寫（回傳解析與檢查結果、忠實度報告） |
| GET／POST | `/api/chapter/storyboard` | 分鏡讀寫（POST 先過 `compile_chapter()`，其他檢查回傳成提醒） |
| POST | `/api/chapter/prompt` | 編譯一格（可帶還沒存的分鏡），回傳 MOSS 提示詞與生圖尺寸 |
| GET | `/api/chapter/panels` | 每格的候選、選圖、裁切、格子尺寸 |
| POST | `/api/chapter/pick` | 選圖／焦點／放大（寫 `picks/`） |
| GET | `/api/image` | 專案裡的圖（`renders/`、`pages/`、`build/`），可帶 `w` 取縮圖 |
| GET | `/api/chapter/crop.jpg` | 一格裁切後的樣子（調焦點時預覽） |
| POST | `/api/task/adapt` | 任務：規劃／劇本／分鏡（`stage`、`pages`、`page`、`force`） |
| POST | `/api/task/render` | 任務：出圖（`page`、`panel`、`more`、`seed`、`preset`、`force`） |
| POST | `/api/task/pages` | 任務：輸出頁面 |
| GET | `/api/chapter/pages` | 每頁的模板、格數、已輸出的 PNG；`export` 欄位：能不能下載（`ready`、`message`、`warnings`） |
| GET | `/api/chapter/export` | 下載 PDF／CBZ（`format`、`page` 省略＝整章、`quality`、`lossless`、`single`）；同時存在 `out/` |
| POST | `/api/task/batch` | 任務：整章批次（`stages`、`force`、`preset`） |
| GET | `/api/bible` | 聖經：定案卡片、草稿、檢查結果、定裝圖狀態 |
| GET／POST | `/api/bible/card` | 讀寫一張卡片（整個 Markdown 檔；存檔後回傳檢查結果） |
| POST | `/api/bible/accept` | 草稿確認入庫 |
| GET | `/api/bible/renders` | 一個角色或地點的定裝圖候選 |
| POST | `/api/bible/pick` | 選定裝圖 |
| POST | `/api/task/bible_extract` | 任務：掃描原著＋成卡 |
| POST | `/api/task/bible_sheet` | 任務：定裝圖出圖 |

## 6. 任務完成後的畫面更新

任務的 `result` 帶 `{"refresh": ["storyboard", ...], "project": …, "chapter": …}`。頁面用 `FE.jobs.onend()` 訂閱，是同一個專案、同一章才重新載入資料；離開頁面時取消訂閱。
